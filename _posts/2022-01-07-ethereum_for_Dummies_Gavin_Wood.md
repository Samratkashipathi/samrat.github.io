Once you get in no way out, only way in is external account

## Guarantees

* **Atomicity**: Either transaction is succeeded else not
* **Synchronous**: No need to think about threading, shared process etc
* **Provenance**: All the messages can be inspected to see the source of the message. These guarantees allow to build security
* **Permanence**: Objects data lasts forever, does not change when computer goes off
* **Immortal**: Object cannot be deleted
* **Immutability**: Objects codes can never be changed


## Key Features

* Servers are Walled Garden (?) -> Monopoly
* Does not give false security, no data is placed in the third party server (?)
* Authenticity -> No third party server auth you, you have private key to get auth

Because of decentralization:

* No Single point of failure, control, or bottleneck in **principle**

Ethereum is an innovation to commons, anyone can build on it and make business out of it. Platform for zero trust computing.
